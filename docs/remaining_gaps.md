# Remaining integration gaps

All locally solvable required Mission Control gaps are closed.

Optional integrations remain open only because a genuine source is absent:

1. Nodes need a canonical registry and per-node health contract.
2. Agents need an explicit agent registry.
3. Logs need an approved bounded, redacted log-source registry.
4. Messenger, WhatsApp and Telegram need current privacy-reviewed connector contracts.

Legacy `/infrastructure`, `/compute`, `/jobs` and `/settings` pages are retained for compatibility and are not part of the canonical sidebar. `/jobs` is superseded by durable `/runs`.
